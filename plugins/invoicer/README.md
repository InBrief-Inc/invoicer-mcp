# Invoicer 2.4.0

Connect your assistant to your Invoicer workspace. See https://invoicer.inbrief.sh/mcp for setup and https://invoicer.inbrief.sh/privacy for data handling.

This package runs the version-pinned npm CLI locally. Requires Node.js 22.18+ and npm. No hosted server is required. Select your workspace in Invoicer before starting the connection; restart after switching workspaces.

Support: support@inbrief.sh
